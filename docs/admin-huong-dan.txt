THIẾT LẬP TRANG QUẢN TRỊ  (public/admin-noi-dung.html)  -  làm MỘT LẦN

Địa chỉ: https://layphatvn.web.app/admin-noi-dung.html
Chỉ xinloi@gmail.com và bachoc@gmail.com vào được (đăng nhập Google).
Trang sửa file .txt trong thư mục content/ của GitHub; mỗi lần Lưu là một commit, web tự deploy lại sau 1-2 phút.

BƯỚC 1 - Bật đăng nhập Google
  Firebase console -> dự án layphatvn -> Build -> Authentication -> Get started -> Sign-in method -> Google -> Enable -> Save.
  (Domain layphatvn.web.app thường đã có sẵn trong Settings -> Authorized domains; nếu chưa, thêm vào.)

BƯỚC 2 - Tạo Firestore và dán luật bảo mật
  Build -> Firestore Database -> Create database (chọn vị trí gần nhất, chế độ production).
  Tab Rules -> xóa nội dung cũ, dán toàn bộ file firestore.rules ở thư mục gốc dự án -> Publish.

BƯỚC 3 - Tạo khóa GitHub (token) chỉ cho kho này
  GitHub -> ảnh đại diện -> Settings -> Developer settings -> Personal access tokens -> Fine-grained tokens -> Generate new token.
  Repository access: Only select repositories -> tuivodich/layphat.
  Permissions -> Repository permissions -> Contents: Read and write.  (Không cấp quyền nào khác.)
  Chọn thời hạn (ví dụ 1 năm) -> Generate -> sao chép chuỗi github_pat_...

BƯỚC 4 - Lưu khóa vào Firestore (để 2 quản trị viên dùng được trên mọi máy)
  Firestore Database -> Data -> Start collection -> Collection ID: admin
  Document ID: github      Field: token  (kiểu string)  Value: dán chuỗi github_pat_...
  Luật ở bước 2 chỉ cho 2 email quản trị ĐỌC tài liệu này.

  Cách đơn giản hơn (không dùng Firestore): bỏ qua bước 2 và 4; lần đầu vào trang, trang sẽ hỏi khóa và lưu trong trình duyệt đó.

LƯU Ý
  - Ai có khóa GitHub này đều sửa được file trong kho. Đừng gửi khóa qua tin nhắn; khi hết hạn hoặc nghi lộ, tạo khóa mới và sửa lại giá trị token.
  - Muốn ẩn bài: mở bài -> Hiển thị: Không -> Lưu. Muốn hiện lại: Hiển thị: Có.
  - Trang không có đường dẫn từ menu và có thẻ noindex; nhưng ai biết địa chỉ vẫn thấy màn hình đăng nhập (không xem được nội dung nếu không phải quản trị viên).

==== LỜI CẦU NGUYỆN (trang loi-cau-nguyen.html) ====
1. Vào Firebase Console > Firestore Database > Rules: dán lại TOÀN BỘ file firestore.rules mới > Publish.
2. Vào admin-noi-dung.html > tab "Lời cầu nguyện":
   - "Số lời tối đa mỗi người mỗi ngày" (1-50, tính theo giờ Việt Nam) và "Từ ngữ cần che" (mỗi dòng một từ) > Lưu cài đặt.
   - Chưa lưu cài đặt thì người dùng chưa gửi được.
3. Người dùng phải đăng nhập Google. Có thể chọn hiển thị tên + ảnh hoặc đăng ẩn danh.
4. Lời gửi lên ở trạng thái "Chờ duyệt". Admin có thể sửa nội dung (kể cả lời đã đăng), rồi bấm
   "Duyệt và đăng", "Gỡ khỏi trang", "Từ chối", "Xóa hẳn", hoặc "Chặn" người gửi.
5. Từ trong danh sách che sẽ được đổi thành *** trước khi lưu (lọc ở trình duyệt; admin duyệt là lớp chặn cuối).

==== REACTIONS (Thích / Thả tim / Cười / Không thích) ====
- Dán lại firestore.rules mới (có thêm phần "reactions") > Publish. Không cần cài đặt gì khác.
- Thành viên phải đăng nhập Google để chọn; mỗi người 1 lựa chọn/bài, bấm loại khác để đổi, bấm lại để bỏ.
- Đã bật cho: bài viết, bài kinh - kệ, lời chúc - cầu nguyện, món chay và từng lời cầu nguyện đã được duyệt (khóa "loi-<id>").
  Muốn tắt một loại: bỏ nó khỏi REACTION_TYPES trong tools/gen_site.py rồi chạy lại.
- Tự đặt ở chỗ bất kỳ: <section class="rx" data-rx="khoa-duy-nhat"></section> + <script type="module" src="reactions.js"></script>.
