Quản trị nội dung

Sửa các file .txt của bài viết. Mỗi lần lưu, web tự deploy lại sau khoảng 1–2 phút.

Đang tải trang quản trị… (bản 5)

Chưa lấy được cấu hình Firebase của web. Dán đoạn cấu hình web (firebaseConfig) vào ô dưới đây. Cách lấy: Firebase console → ⚙ Project settings → General → Your apps → ứng dụng Web (nếu chưa có, bấm biểu tượng </> để thêm) → mục SDK setup and configuration → chọn "Config" → sao chép đoạn { apiKey: "...", authDomain: "...", ... }.

Đăng nhập bằng tài khoản Google của quản trị viên.

Tài khoản không có quyền quản trị trang này.

Chưa lấy được khóa truy cập GitHub (mã token) từ Firebase. Dán khóa vào ô dưới đây (chỉ lưu trong trình duyệt này), hoặc xem file hướng dẫn để lưu khóa vào Firebase.
